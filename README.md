# CanoRent – Rental Billing & Inventory Management System

## Overview

CanoRent is a rental billing and inventory management system developed for freelance clients to simplify and automate rental business operations. The application helps businesses manage rental bookings, item availability, billing operations, stock tracking, and customer enquiries through a centralized system.

The platform was designed to improve operational efficiency by allowing users to:

* Check rental item availability for specific dates and time periods
* Manage billing and inventory workflows
* Track stock movement and rental status
* Handle customer enquiries and bookings efficiently

> Note: This repository is a project showcase and documentation repository. Production source code and client business data are not publicly available due to confidentiality requirements.
